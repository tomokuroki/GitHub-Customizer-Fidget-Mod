# GitHub Customizer & Fidget Mod

[Developer: @tomokuroki](https://github.com/tomokuroki)  
Manifest V3 Extension  
Chrome | Edge | Firefox | Safari Compatible  

---

## Overview

An all-in-one productivity and customization extension for GitHub.  
It enhances UI styling, injects helper scripts, and adds an interactive contribution-board fidget Pop It directly into the browser toolbar.

---

## Features

### 1. Premium Color Themes

The extension provides global GitHub theme overrides:

| Theme Name       | Description |
|------------------|-------------|
| Coffee Shop      | Dark espresso-style background with warm accent tones |
| AMOLED Black     | Pure black UI optimized for OLED displays with neon highlights |
| Midnight Purple  | Deep violet theme with soft glowing accents |
| Calm Dark        | Minimal slate-blue theme designed for low eye strain |

---

### 2. Focus Mode (Zen Mode)

Removes interface distractions on repository pages:
- Hides GitHub header navigation
- Hides sidebars
- Hides footer elements
- Centers code and markdown content for focus reading

---

### 3. Interactive Contributions Calendar

Enhances GitHub contribution graph with:
- Smooth hover animations
- Scaling and glow effects on interaction
- Visual feedback improvements

---

### 4. Floating Back-to-Top Button

A persistent navigation button appears on scroll:
- Works on repositories, issues, pull requests
- Smooth scroll animation back to page top

---

### 5. Fidget Pop It Board

Interactive contribution-style fidget board inside the extension popup:
- Clickable grid interaction
- State persistence in local storage
- Audio feedback using Web Audio API
- Randomized pitch for natural interaction feel

---

### 6. Developer Info Card

Displays live GitHub profile data via GitHub REST API:
- Avatar
- Name
- Bio
- Followers
- Repository stars

Target profile: @tomokuroki

## Installation

### Chrome / Edge / Brave / Opera

1. Open extensions page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. Enable Developer Mode
3. Click Load Unpacked
4. Select extension directory containing `manifest.json`
5. Pin extension to toolbar

---

### Firefox

1. Open `about:debugging`
2. Select This Firefox
3. Click Load Temporary Add-on
4. Choose `manifest.json`
